# Pure Tokens Switch 0.4.0

This version adds Hermes, EvoX and VS Code configuration, read-only Hermes and VS Code sessions, and improvements to configuration recovery, client detection, update progress and sharing. Cursor support has been removed.

## Client Configuration

- Add Hermes one-click configuration, compatible model/default selection, previews and backup restoration. Disable discovery for managed providers to exclude unselected models and image/video generators without changing personal providers.
- Add EvoX two-file configuration with protocol-specific providers, model/default selection, image-input declarations, previews and restoration. Fully quit EvoX first. No automatic restart or takeover of personal providers, history or Skills/MCP.
- Write VS Code's own model groups directly without installing extensions or changing other providers or defaults. One-click setup never starts or restarts the editor. Users can restart themselves or confirm the separate post-configuration restart action. Use native custom-endpoint template budgets without claiming verified per-model context limits.
- Disclose plaintext keys in native client configuration before confirmation. A successful VS Code file write does not prove runtime activation; existing Chat enablement remains unchanged.
- Remove Cursor configuration, restore and restart entry points, and reject stale host operations. Preserve existing configuration, keys and backups without uninstalling or closing Cursor. The catalog contains 17 clients; catalog membership does not guarantee one-click configuration availability.
- Keep experimental TraeWork setup and automatic restore unavailable. Model previews and existing configuration remain; requests stop before closing the editor.
- Keep installed clients first, with the default order within each group. Octop remains supported and appears last by default.
- Use the active environment's endpoint in configuration, previews, copy actions and model examples instead of displaying the production URL during local testing.
- Configure image input in DSH Desktop, Pi, OpenCode, Qoder and WorkBuddy only from explicit server declarations. Unknown capabilities preserve existing manual settings.

## Recovery And Sessions

- Restore vendor configuration only for the selected client, named in the confirmation. Read failures no longer directly demand restoration. Octop retains reference protection and distinguishes expired authentication from transaction failures.
- Prevent repeated configuration from restoring an older Pure Tokens key or route. Add interruption recovery, rollback and internal-state cleanup; incomplete restoration preserves backups without overwriting external edits.
- Let diagnostics clear unwritten preparation-stage journals without backups. Fix stale configuration activation after account switches, false failures after successful restoration, and stale inspection results after switching clients.
- Add read-only Hermes and VS Code local session lists, search, redacted previews and refresh. Delete, restore and resume remain unavailable. EvoX session management is not enabled.
- Improve long Pi and Gemini history reads and bounded OpenCode previews, marking incomplete content explicitly.

## Experience And Reliability

- Windows discovery separates installation paths, product identity and version metadata. A native application picker saves verified locations for revalidation without launching the application; missing versions and unconfirmed identity are distinct from absence.
- Quit, restart and restore messages identify the host or Switch itself. Keep unrelated terminals and SSH connections open; service-version errors no longer suggest a generic restart. Restore results explicitly leave other applications and Switch settings unchanged.
- Key preparation failures show the failed stage and offer sanitized diagnostic copying without a terminal launch. Successful preparation no longer depends on another key inventory read or UI draft save; Native authentication and group coverage checks remain required.
- Move client detection off the IPC thread and reuse valid version results. Improve Windows detection and launch for custom installation paths, invalid icon registrations and missing App Paths.
- Show sign-in retry countdowns and prevent duplicate submissions. Stop background key hydration on rate limiting; matching BFF/gateway changes are required.
- Share update state across sign-in, navigation and settings. Show download, verification and installation progress; retry after connectivity returns and prevent duplicate installation tasks or false up-to-date results.
- Reveal the entire share dialog only after data, images, fonts and QR codes are ready. Show no overlay, empty frame or loading message during preparation, and leave the current page usable. Support retries and smooth dismissal without flashing incomplete artwork.
- Open third-party model evaluation reports without copying connection details or providing keys. Fix image/video price displays missing the default discounted multiplier.
- Synchronize compatibility matrices, configuration fixtures and browser regressions. Limit development cache growth while preserving Release artifacts.

## Usage Boundaries

- Configuration support does not mean every host version, model or tool-call combination has been verified. Confirm model availability in the target application after applying.
- Image-input capabilities and rate-limit guidance depend on companion service metadata. Website and desktop catalogs may differ as they are updated independently.
- Previously published 0.3.1 installers are unchanged. Upgrade through official installers or the built-in Switch updater.
