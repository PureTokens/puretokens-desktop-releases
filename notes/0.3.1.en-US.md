# Pure Tokens Switch 0.3.1

- Fixed Windows Octop detection for custom installation directories and executables without version resources. Missing version information no longer implies that Octop is not installed.
- Installed clients now appear first in the client selector, retaining the default order within each group and updating after redetection.
- Unified desktop installation detection by separating installation state, version, and configuration state; added product-specific Windows registration and Codex AppX version evidence, without treating leftover configuration as installation proof.
- Octop restoration is offered only after backup and reference checks pass. Z.ai official-price icons retain their original colors.

- Aligned the Z.ai provider icon with Web.

- Fixed normal Octop WAL databases being reported as damaged. Read failures now offer redetection instead of invalid restoration, and restore failures explain the restrictions.

- Added Octop configuration. Initialize and close Octop before applying, then reopen it and select a Pure Tokens model. Apply and restore affect only the managed provider, never the chat database; referenced providers are not deleted. Windows device and live-request acceptance remain pending.

- Usage troubleshooting now opens Model Plaza inside Switch, with a highlighted VPN hint beside its title. Cumulative and daily costs show two decimal places and K/M abbreviations without changing individual record precision.

- Sharing posters match Web with Chinese artwork for Simplified Chinese and English artwork for all other languages, live statistics, account details, invitation QR and up to 12 server-selected supplier models. Model names use uniform font sizes and truncate overflow with `...`. Concurrent rendering no longer overlaps text.
- Page navigation now uses an outgoing and incoming perspective page-turn animation without resetting retained pages, respecting reduced-motion preferences.
- DSH Desktop can restore missing associations in existing original workspaces with registry backups, preserving transcripts and archive states. Native workspace checks passed; actual sidebar/open acceptance remains pending.

- Kimi Code can restore misplaced main-agent session trees with full backups when agent paths still point to the original destination. Native listing and wire export passed isolated verification; interactive continuation remains pending.

- Kimi Code session reading now rejects mismatched directory and state IDs instead of exposing conflicting identities.

- Grok Build can relocate misplaced flat session directories within default storage with complete backups. Native local listing passed verification; authenticated loading and continuation remain pending. Nested directories and long hashed paths are unsupported.

- Grok Build no longer offers continuation when its resume log is missing, empty, unreadable, or malformed.

- Claude Code can restore misplaced standalone text transcripts to their original project folder with backups. Tool state, attachments, and companion directories are not supported. Official SDK list/message checks passed in isolation; interactive CLI continuation remains unverified.

- OpenCode can restore missing database sessions from intact legacy JSON history without changing IDs, project ownership, or content. Existing rows are never overwritten. Native list/export passed isolated verification; interactive continuation and Windows device acceptance remain pending.

- Added backed-up Pi v3 project-history recovery, Gemini JSONL reading and registered-project filename repair, and missing Qoder sidebar-row registration with a recovery receipt. Original transcripts remain intact; conflicts, archived/deleted rows, and custom roots are not repaired. Continuing a session is distinct from restoring its native history entry. Native UI and continuation acceptance remain pending.

- Distinguished failed and incomplete session reads from empty history, added persistent preview errors and retry, and clarified that resume requests still require host confirmation.

- Expanded npm and standalone version detection with executable-to-package identity checks. Added Windows desktop product-resource detection; device validation remains pending.

- Fixed missing versions for verified standalone Grok Build, OpenCode, and Kimi Code installations.

- Fixed Model Plaza scrolling when content exceeds the window height; top navigation stays fixed.
- Added Kimi Code and ZCode text previews. ZCode supports stable WAL snapshots; Kimi retains completed history with a partial-result notice during incomplete writes. Kimi supports the limited directory repair described above; ZCode history repair and deletion for both clients remain unsupported.

- Added Model Plaza to the avatar menu, with in-app model filters, pricing, live status, API examples, model ID copying and network reference images. Status presentation, caching and retries follow the Web model plaza.
- Aligned model price units and formatting, localized search, filter reset, API examples, detail drawers and network image previews with Web. Fixed video resolution prices incorrectly labeled per second.

- Added Claude Desktop local session lists and text previews, plus backed-up repair of a missing local_ filename prefix on intact Code indexes within their original account. Missing-index reconstruction, ordinary cloud chats and deletion are unsupported; native sidebar and continuation verification is pending.

- Added DSH Desktop session lists and text previews from its default local storage, with limited repair of a missing original-workspace association as described above. Deletion remains unavailable; native sidebar and continuation acceptance remain pending.

- Kimi Code lists and text previews use its default data directory and show message totals as unknown. Limited original-directory repair is described above; deletion remains unsupported.

- Added WorkBuddy and Qoder project history previews for default data directories. Qoder supports the limited missing-sidebar-row repair described above; WorkBuddy history repair and deletion for both clients remain unsupported.

- Selected navigation items highlight only their text and icons.

- Retained the warm orange and pink workspace background with lighter glass and edge highlights; removed obsolete visual guidance and inactive decoration.

- Removed legacy dark styles; the client retains its fixed light appearance regardless of system settings.

- Updated the login background to the blue-sky glass platform artwork; sign-in behavior is unchanged.
- Refined the sign-in panel with frosted glass, highlighted edges, input icons, and an orange gradient button.
- Matched the bottom feature strip to the sign-in panel's frosted glass and highlighted edges.
- Refined the workspace background, navigation, and client configuration with lighter materials and fewer decorative effects, without changing workflows.

Improvements to action notifications, scrolling, and client restarts. This version is pending candidate construction and acceptance, not yet released.

- Building on 0.3.0, action notifications use compact tinted liquid-glass bars in the upper right. Emerald, amber, red, and blue indicate status, with dark text on the fixed light appearance; multiline text, dismissal, and recovery actions remain available without automatic headings.
- Unavailable or pending enhancement settings allow a confirmed ordinary ChatGPT restart without changing saved settings. The launch mode is fixed when confirmation opens.
- Native scrollbars are hidden while wheel, touchpad, and keyboard scrolling in focusable regions remain available. Scrollbar-thumb dragging is no longer available.
- Notification details display monetary amounts without raw quota counters that could be mistaken for wallet balances or Token counts. Titles and body text remain server-owned.
- Redemption distinguishes membership activation from wallet credit and presents their outcomes separately.
- The billing page adds the promotion plan and share copy containing the inviter, server-recommended models and registration link. Reward percentages come from the server; invitation records support live data, pagination and retries.
- The vibrant-orange purchase action remains prominent. Top-up history is a clock-icon text link below the code input. Promotional animations respect reduced-motion settings.
- Skill entries offer Copy installation prompt next to Open, ready to paste into the current client. Switch does not install Skills automatically.

A new candidate and fresh acceptance evidence are required; the 0.3.0 candidate cannot substitute for this version. Inherited features are documented in the [0.3.0 notes](0.3.0.en-US.md); the new behavior above supersedes the corresponding older UI descriptions.
