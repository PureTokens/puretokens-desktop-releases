# Pure Tokens Switch 0.4.0

本版新增 Hermes、EvoX 和 VS Code 配置支持，以及 Hermes、VS Code 的只读会话管理；改进配置恢复、客户端检测、更新进度和分享体验。Cursor 支持已移除。

## 客户端配置

- 新增 Hermes 一键配置、兼容模型与默认选择、配置预览及备份恢复。受管供应商关闭模型自动发现，避免加入未选模型或图片、视频生成模型；个人供应商不受影响。
- 新增 EvoX 两文件配置，支持协议供应商、模型与默认选择、图片输入声明、预览和备份恢复。配置前须完全退出 EvoX；不自动重启，不接管个人供应商、历史或 Skills/MCP。
- VS Code 直接写入自有模型组，不安装扩展、不接管其他提供器或默认设置，一键配置不启动或重启编辑器。用户可自行重启，或使用配置完成后的独立重启按钮并确认。采用原生自定义端点模板的上下文预算，不承诺每个模型的实际上下文上限。
- 配置确认时披露客户端原生文件中的明文 Key 存储。VS Code 文件写入成功不等于运行时已启用，原有 Chat 启用状态保持不变。
- 移除 Cursor 配置、恢复和重启入口；旧请求不能再操作宿主。保留已有配置、Key 和备份，不卸载或关闭 Cursor。支持目录现为 17 个客户端，不代表所有客户端均开放一键配置。
- TraeWork 实验配置与自动恢复暂不可用，保留模型预览及现有配置，请求在关闭编辑器前停止。
- 客户端列表保持已安装优先，其余按默认顺序展示；Octop 保留支持并默认置于组内末尾。
- 配置页、预览、复制和模型广场使用当前运行环境的服务地址，修复本地测试显示线上 Base URL 的问题。
- DSH Desktop、Pi、OpenCode、Qoder、WorkBuddy 按服务端明确声明配置图片输入能力，未知能力保留已有手动设置。

## 恢复与会话

- 恢复官方配置仅针对所选客户端，确认框明确目标；配置读取失败不再直接要求恢复。Octop 保留引用保护，并区分登录失效与事务错误。
- 修复重复配置后恢复出旧 Pure Tokens Key 和路由的问题。补齐中断恢复、失败回滚与内部状态清理，未完成恢复保留备份，不覆盖外部修改。
- 诊断页支持清理尚未写入、未产生备份的准备阶段残留。修复账户切换重新启用旧配置、恢复成功后刷新失败误报，以及切换客户端后旧检查结果覆盖的问题。
- Hermes、VS Code 新增本地会话列表、搜索、脱敏预览和刷新，仅提供只读能力，不开放删除、恢复或继续会话。EvoX 会话管理仍未开放。
- 改善 Pi、Gemini 长会话读取和 OpenCode 大会话预览，明确标记不完整内容。

## 体验与稳定性

- 退出、重启及恢复提示明确具体宿主或 Switch 本身；保留无关终端和 SSH 连接，服务版本问题不再笼统要求重启。恢复结果明确其他应用和 Switch 设置未修改。
- 一键配置凭证准备失败可显示失败阶段并复制脱敏诊断，无需从终端启动 Switch；准备成功不再因重复列表读取或界面草稿保存失败阻断正式写入，仍保留 Native 鉴权和分组覆盖检查。
- Windows 客户端检测不再仅依赖产品显示名称，综合安装登记、程序元数据和稳定标识；区分未安装、身份无法确认与已安装但版本未知。自动检测失败时可选择程序位置，保存后每次重新校验，不启动或重启客户端。
- 客户端检测改为后台执行并复用有效版本信息。改善 Windows 自定义安装目录、无效图标登记与无 App Paths 场景的检测和启动。
- 登录受限时显示重试倒计时并防止重复提交；后台 Key 同步遇到限流停止本轮请求，需要配套 BFF/网关更新。
- 登录页、导航栏和设置页共享更新状态，显示下载进度、校验及安装状态，支持网络恢复后重试，避免重复安装任务和失败时误报最新版。
- 分享海报等待数据、图片、字体及二维码就绪后才显示整个弹窗；加载中不显示遮罩、空框或生成提示，也不阻挡当前页面。支持失败重试与平滑关闭，避免空白或半成品闪现。
- 模型测评直接打开第三方报告，无需复制连接信息或提供 Key。修复图片、视频价格展示未应用默认优惠倍率的问题。
- 同步兼容矩阵、配置样本和浏览器回归；控制开发构建缓存体积，保留 Release 产物。

## 使用边界

- 客户端配置支持不等于所有宿主版本、模型或工具调用组合均已验证。文件写入成功后，请在目标应用中确认模型可用。
- 模型图片输入能力和限流提示依赖配套服务提供的信息；官网目录与桌面支持范围可能因各自更新进度不同而有差异。
- 本版不修改已发布的 0.3.1 安装包；升级请使用官方安装包或 Switch 内置更新入口。
