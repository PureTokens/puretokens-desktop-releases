# Pure Tokens v0.1.0-beta.1

Pure Tokens 首个真实桌面发行版本。

- 支持 macOS Apple Silicon。
- 支持账户密码登录、五客户端检测、四客户端受管配置与 Trae 手动配置教程。
- 支持用量日志、充值码、个人资料、托盘、开机启动和透明用量组件。
- 已接入带签名校验的 Tauri Updater，本版本用于建立 Beta 更新基线。

## 安装说明

本 Beta 测试包使用 ad-hoc 签名，尚未完成 Apple Developer ID 签名与公证。首次打开如被 macOS 阻止，请在“系统设置 → 隐私与安全性”中确认打开。
