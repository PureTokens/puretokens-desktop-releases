# Pure Tokens Switch 0.3.1

- 修复 Windows 上 Octop 安装在自定义目录、程序未提供版本资源时被误报为未安装的问题；版本缺失不再等同于未安装。
- 客户端列表优先显示已安装的客户端，同组保留默认顺序，重新检测后自动更新排序。
- 统一桌面客户端安装检测：分离安装状态、版本和配置状态，支持产品专属 Windows 安装登记及 Codex AppX 版本识别；配置残留不再单独表示已安装。
- Octop 恢复入口仅在匹配备份及引用检查通过后显示；模型广场 Z.ai 官方价格图标保留原色。

- Z.ai 供应商图标与 Web 端统一。

- 修复 Octop 正常 WAL 数据库被误报为损坏；读取失败引导重新检测，不再推荐无效恢复，恢复失败补充限制说明。

- 新增 Octop 一键配置：先在 Octop 完成初始化并退出，再应用配置，重开后选择 Pure Tokens 模型。配置和恢复仅处理受管 Provider，不覆盖聊天数据库；被代理引用的配置不会直接删除。Windows 真机与实际请求仍待验收。

- 使用记录中的模型广场链接改为直接进入客户端内页面；标题旁增加高亮 VPN 提示。累计和今日费用保留两位小数，大额使用 K/M 缩写，不改变单条记录的金额精度。

- 分享海报与 Web 统一为天空人物视觉，简体中文使用中文素材，其他语言使用英文素材；展示真实统计、用户信息、邀请二维码及最多 12 个服务端推荐供应商模型。模型名称统一字号，超长以 `...` 省略，并修复异步绘制重影。
- 页面切换增加双页面透视翻页动画，保留缓存页面状态，并遵循系统减少动态效果设置。
- DSH Desktop 支持补回原工作区缺失的会话关联，备份注册表并保留正文和归档状态；原生工作区验证通过，实际侧栏打开仍待验收。

- Kimi Code 增加完整主代理会话树错位恢复，保留原记录并完整备份；仅支持代理路径仍指向正确目标的记录。原生列表与正文导出已验证，交互续聊仍待验收。

- Kimi Code 会话读取新增目录与记录 ID 一致性校验，避免显示身份冲突的记录。

- Grok Build 支持默认根平铺会话目录错位恢复，完整备份并保留原记录。原生本地列表验证通过；打开及续聊需要登录后验收，子目录和长路径哈希暂不支持。

- Grok Build 缺少有效恢复日志时禁用“在宿主中继续”，避免仅有摘要的记录误显示为可继续。

- Claude Code 增加独立文本会话的原项目目录恢复，保留原记录并备份；不支持工具、附件及附属目录。官方 SDK 列表/正文已隔离验证，终端交互续聊仍待验收。

- OpenCode 支持从完整旧版 JSON 历史补回缺失的数据库会话，保留原 ID、项目及内容，不覆盖已有记录。原生列表/导出已隔离验证，交互续聊和 Windows 真机仍待验收。

- Pi 增加完整 v3 会话的原项目历史目录恢复；Gemini CLI 增加 JSONL 历史读取和已注册原项目的文件名修复；Qoder 增加缺失原会话侧栏索引补建。保留原记录，文件修复有备份，Qoder 保存恢复记录。不覆盖冲突或归档、删除状态，不支持自定义目录。CLI“继续会话”与“恢复历史列表”分别展示，实际宿主界面和续聊仍待验收。

- 区分会话读取失败、不完整扫描与空历史，详情失败支持重试；恢复提示明确需到宿主确认结果。

- 扩展 npm/独立安装的版本检测，避免读取另一份安装的版本；新增 Windows 桌面应用产品版本资源读取（真机待验证）。

- 修复 Grok Build、OpenCode、Kimi Code 已验证的独立安装方式不显示版本号的问题。

- 修复模型广场内容超出窗口后无法滚动的问题，顶部导航保持固定。
- Kimi Code、ZCode 新增文本预览，过滤思考和工具内容；ZCode 支持稳定 WAL 副本，Kimi 未完成消息不阻塞已有历史并显示部分读取提示。Kimi 支持上文限定的原目录恢复；ZCode 不支持恢复，两者均不支持删除。

- 头像下拉菜单新增模型广场，可在 Switch 内筛选模型、比较价格、查看实时状态与 API 示例，支持复制模型 ID 和网络检测参考图。状态展示、缓存和重试逻辑与 Web 模型广场一致。
- 模型广场进一步同步 Web 的价格单位与格式、中文搜索、筛选重置、调用示例、详情抽屉和网络图片预览，修复视频分辨率价格被误标为每秒的问题。

- 新增 Claude Desktop 本地会话列表与文本预览；完整 Code 索引缺少 local_ 文件名前缀时可备份并修复，不变更原账号归属。不包含普通云端聊天、缺失索引重建或删除；原生侧栏和续聊待验收。

- 新增 DSH Desktop 默认目录下的会话列表和文本预览，支持上文限定的原工作区缺失关联修复；不支持删除，原生侧栏与续聊仍待验收。

- Kimi Code 默认目录下支持会话列表、文本预览及上文限定的原目录恢复；不支持删除，消息总数显示未知。

- 新增 WorkBuddy、Qoder 默认目录下的会话记录与消息预览；Qoder 支持上文限定的缺失侧栏行补建，WorkBuddy 不支持历史恢复，两者均不提供删除。

- 顶部导航选中时仅高亮文字和图标。

- 主界面保留暖橙、粉色背景，配合清透玻璃和边缘高光；清理旧视觉规范及停用装饰。

- 清理历史深色样式，客户端保持固定浅色，不随系统外观变化。

- 登录页采用新的蓝天玻璃平台背景，登录功能不变。
- 登录框优化为磨砂玻璃高光边缘、带图标输入框和橙色渐变按钮。
- 登录页底部介绍同步采用磨砂玻璃与高光边缘，统一视觉风格。
- 主界面背景、导航与客户端配置页采用清透工作台视觉，减少装饰和叠加阴影，保持操作流程不变。

优化操作提示、滚动体验和客户端重启。当前为待构建、待验收版本，不代表已经发布。

- 在 0.3.0 功能基础上，操作提示改为右上角紧凑液态玻璃条，以翠绿、琥珀、红、蓝区分状态，正文固定使用深色文字；保留多行文字、关闭和恢复动作，不再自动添加标题。
- 增强设置读取失败或尚未完成时，可确认后以普通模式重启 ChatGPT；不修改已保存的设置，并固定本次确认的启动模式。
- 隐藏客户端原生滚动条，保留滚轮、触控板及可聚焦区域的键盘滚动，不再提供滑块拖动。
- 通知详情只显示金额，移除容易与余额或 Token 数量混淆的原始额度数值；标题和正文仍由服务端提供。
- 充值页区分会员激活码与余额充值码，分别展示处理结果。
- 充值页新增推广计划与邀请分享，支持复制包含邀请人、平台推荐模型及注册链接的文案；奖励比例来自服务端，邀请记录支持真实数据、分页及失败重试。
- 保留活力橙购买入口；充值记录改为输入框下方的时钟图标文字链接。推广动画尊重系统减少动态效果设置。
- Skill 的“打开”旁新增“复制安装提示词”，可粘贴到当前客户端安装链接中的 Skill；Switch 不自动执行安装。

本版本必须创建新候选并重新验收；不得使用 0.3.0 候选包代替。完整继承功能见 [0.3.0 说明](0.3.0.zh-CN.md)，本页的新行为覆盖其中相应的旧界面说明。
