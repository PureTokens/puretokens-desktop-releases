# Pure Tokens Switch 0.2.7

Reliably move an accepted Stable candidate into public delivery.

Pure Tokens Switch 0.2.7 fixes candidate integrity verification. Before a candidate reaches device acceptance, its Manifest, signatures, and package bytes are now checked using the asset naming rule GitHub Releases actually publishes. This catches a naming mismatch during the candidate stage instead of failing only when the accepted candidate is made public.

## What’s improved

- **More reliable delivery**: Candidate assembly and public publication use the same macOS and Windows asset-name matching rule, and verify the Manifest target, updater signature, and integrity evidence before acceptance.
- **No change to day-to-day use**: Account flows, client configuration, model requests, local data, and privacy boundaries are unchanged.

Thank you for using Pure Tokens Switch.
