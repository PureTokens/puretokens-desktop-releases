# Pure Tokens Switch 0.2.8

More reliable updates and a clearer community browsing experience.

Pure Tokens Switch 0.2.8 fixes free-resource covers that could fail to appear in the desktop app, keeps the Skills / Prompts and Free resources pages visually stable while they first load, and makes update failures easier to understand and recover from.

## What’s improved

- **Free-resource covers load reliably**: Covers now use an independent public, restricted content path instead of incorrectly depending on the signed-in session.
- **Smoother community loading**: Skills / Prompts and Free resources show category and card skeletons on first load. Individual covers show a lightweight loading state and a clear fallback if unavailable.
- **Clearer update recovery**: Manifest, download, verification, and install-replacement failures are distinguished. Your current version is kept, and the Pure Tokens download page is available for a clean reinstall.
- **A more resilient update path**: The client falls back to the same Stable manifest only when its static rollout manifest cannot be read. It retries only transient download failures once and never retries a failed verification or app replacement.

Thank you for using Pure Tokens Switch.
