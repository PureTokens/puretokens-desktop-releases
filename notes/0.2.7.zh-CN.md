# Pure Tokens Switch 0.2.7

让已经完成验收的正式版本能够可靠地进入公开发布。

Pure Tokens Switch 0.2.7 修复了发布候选的完整性核验：候选在进入真机验收前，会按 GitHub Release 实际发布时的资源命名规则校验 Manifest、签名和安装包字节的一致性。这样可在候选阶段发现命名差异，避免已验收的候选在公开发布阶段才失败。

## 本次更新

- **更可靠的发布交付**：候选组装与公开发布使用同一套 macOS/Windows 资源名匹配规则，并在验收前核对 Manifest 指向的安装包、Updater 签名和完整性证据。
- **不改变日常使用**：账户、客户端配置、模型请求、本地数据和隐私边界均保持不变。

感谢你使用 Pure Tokens Switch。
